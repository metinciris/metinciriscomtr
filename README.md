# Web Site Yenileme Projesi

Modern, performans odaklı ve kullanıcı dostu bir web sitesi yenileme projesi. Bu proje, mevcut web sitesini en güncel teknolojilerle modernize etmeyi hedefler.

## 🚀 Teknolojiler

- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS 4, Radix UI
- **Animasyon:** Motion (Framer Motion)
- **Veri/Backend:** Supabase
- **Grafik:** Recharts
- **Araçlar:** Lucide React, Dompurify, Sharp

## 🛠️ Kurulum

Yerel geliştirme ortamını kurmak için aşağıdaki adımları izleyin:

1. **Bağımlılıkları Yükleyin:**
   ```bash
   npm install
   ```

2. **Geliştirme Sunucusunu Başlatın:**
   ```bash
   npm run dev
   ```

3. **Üretim sürümü Oluşturun:**
   ```bash
   npm run build
   ```

## 📂 Proje Yapısı

- `src/components`: Yeniden kullanılabilir UI bileşenleri.
- `src/pages`: Sayfa bileşenleri.
- `src/hooks`: Özel React hook'ları.
- `src/services`: API ve dış servis bağlantıları.
- `src/data`: Statik veri dosyaları.
